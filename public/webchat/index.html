                                                        How the pieces fit together.
                                                        

            
                                                        
              
                                                        
                
                Rooms
              
                                                        
              
                                                        
                A room is a chat space. Each room is its own conversation — what you say in one room
                doesn't show up in another. Pick a room from the sidebar to open it.
              
                                                        
            
                                                        

            
                                                        
              
                                                        
                
                Agents
              
                                                        
              
                                                        
                An agent is the assistant you're talking to — it has its own personality, workspace, and
                memory. The same agent can be in several rooms at once: it keeps one shared memory across
                them (tell it something in one room and it can recall it in another), but each room stays
                a separate conversation.
              
                                                        
            
                                                        

            
                                                        
              
                                                        
                
                Models
              
                                                        
              
                                                        
                Every agent runs on a model. By default that's Claude. From Models you can assign a
                different model to an agent — including a local one running on your own hardware via
                Ollama. The model only changes how the agent thinks; its memory and rooms stay the same.
              
                                                        
            
                                                        

            
                                                        
              
                                                        
                
                Wiring rooms and agents
              
                                                        
              
                                                        
                Wiring is the link between a room and an agent. A room can have one agent or several. With
                one agent, it replies to everything. With several, star one in the room's settings to make
                it the default that replies to every message; the others reply only when you @-mention them.
              
                                                        
            
                                                        

            
                                                        
              
                                                        
                
                Threads
              
                                                        
              
                                                        
                A thread is a separate conversation inside a room, with the same agent. Use one to take a
                topic onto its own track without cluttering the main chat. Open a room's threads from the
                # button in its header, or expand the room in the sidebar; + starts a new one.
              
                                                        
              
                                                        
                A thread shares the agent — its personality, workspace, skills, and long-term memory
                all carry over, so anything the agent has saved to memory it can still recall. What a thread
                does not share is the conversation itself: it starts blank, and the agent in a thread
                can't see the main chat or any sibling thread (and they can't see it). That's the point —
                each topic stays focused, and each turn is smaller, cheaper, and faster.
              
                                                        
            
                                                        

            
                                                        
              
                                                        
                
                Pulling & pushing context
              
                                                        
              
                                                        
                Because a thread starts blank, two buttons in its header move context across the line.
                Pull (↓) copies the main chat's recent messages down into the thread — use it to give
                the thread the background it needs. Push (↑) copies the thread's own messages up into
                the main chat — use it to fold a thread's outcome back into the main conversation.
              
                                                        
              
                                                        
                Both only ever add — they never overwrite or reorder what's already there — and each is
                incremental: a second pull or push brings only what's new since the last one. A divider
                marks where the copied-in block begins.
              
                                                        
            
                                                        

            
                                                        
              
                                                        
                
                Pinning & hiding rooms
              
                                                        
              
                                                        
                Drag a room to the top of the sidebar to pin it; drag pinned rooms to reorder them (or use
                Move up / Move down in a pinned room's … menu). To tuck a room away, choose Hide from its
                … menu — hidden rooms reappear with the "Show hidden" toggle at the bottom of the list.
                Admins can also Archive a room, which removes it for everyone.
              
                                                        
            
                                                        

            
                                                        
              
                                                        
                
                User credentials
              
                                                        
              
                                                        
                By default an agent bills its work to the workspace's own account. A room owner can turn on
                user credentials so each person connects their own Anthropic API key or Claude subscription
                and their turns bill to their own account. Per room it's one of three modes: off (no
                one connects a key), optional (connect one if you want), or required (you must
                connect one to chat). When a room offers it, use the key icon in the room to connect or
                disconnect — your key is never shown to the agent.

                    Auto routing
                    
                    
                    
                       Installed
                    
                  
                                                        
                  
                                                        
                    Sends each message to the model that fits it — quick turns go to a
                    small local model, hard ones escalate to Claude. A local
                    Arch-Router classifier (running on Ollama) reads the conversation
                    and picks a route; a LiteLLM proxy carries the call to the chosen
                    model, falling back to Claude whenever the local answer isn't good
                    enough. A nightly job recalibrates the routes from real traffic.
                    Runs fully on this machine — no extra cloud services.
                  
                                                        
                  
                                                        
                  
                                                        
                    
                                                        
                    
                                                        
                    
                                                        
                  
                                                        
                
                                                        
                
                                                        
                  
                                                        
                    Read aloud
                    
                    
                    
                       Installed
                    
                  
                                                        
                  
                                                        
                  
                                                        
                    Adds a speaker control to agent replies — nothing plays until you
                    tap it. Installing runs Kokoro — an open-source neural voice — in a
                    local Docker container (kokoro-fastapi, ~330MB model, loopback
                    only), so speech is generated on this machine and nothing leaves
                    it. Without the install, the control falls back to each device's
                    built-in voices. The switch below applies to everyone in the
                    workspace.
                  
                                                        
                  
                                                        
                    
                    
                                                        
                      
                      
                    
                                                        
                  
                                                        
                  
                  
                                                        
                    Voice
                    
                  
                                                        
                  
                                                        
                    
                                                        
                    
                                                        
                  
                                                        
                
                                                        
                
                
                                                        
                  
                                                        
                    Voice dictation
                    
                    
                    
                       Installed
                    
                  
                                                        
                  
                                                        
                  
                  
                                                        
                    
                                                        
                      
                      
                    
                                                        
                  
                                                        
                  
                                                        
                    Adds a mic to the message box: tap, speak, and the transcript lands
                    in the composer — sending stays your tap. Local (recommended) runs
                    whisper.cpp in a Docker container with a Whisper model sized to
                    this machine; audio never leaves it. ElevenLabs transcribes in the
                    cloud with your API key — audio is sent to ElevenLabs. The cleanup
                    model optionally tidies punctuation and fillers after you stop.
